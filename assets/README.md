# L++ v0.1 brand assets

These vectors are the canonical L++ v0.1 marks.

| Asset | Use |
| --- | --- |
| `lpp-logo.svg` | Primary mark for README, hero artwork, video opening/end cards, thumbnails, and large placements. |
| `lpp-icon.svg` | Compact mark for UI, editor/terminal chrome, avatars, favicons, and small placements. |
| `lpp-icon-16.svg` | 16-pixel compatibility alias for existing website references. |

## Usage rules

- Preserve the 1:1 aspect ratio and original colors.
- Do not stretch, rotate, skew, recolor, or typeset a replacement `L++` mark.
- The split black/orange tile is the canonical L++ mark.
- At small rendered sizes, use `lpp-icon.svg` or `lpp-icon-16.svg`.
- Keep enough clear space around the mark that the rounded background tile remains visually separate from adjacent text.

The website copies live under `website/public/` and should remain byte-equivalent to their canonical counterparts in `assets/`.
