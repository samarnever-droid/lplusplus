# L++ v0.3.2 Release Notes

**Milestone:** Language ergonomics — the largest syntax/semantics update since v0.3.0.

## Literals & lexical syntax
- Scientific notation floats (`1e5`, `1.5e-3`, `2.5E+10`), finite-checked.
- Octal integers (`0o755`).
- Numeric suffixes: `u8 u16 u32 u64 usize i8 i16 i32 i64 isize f64`, range-checked (`255u8`, `10_i32`, `1e3f64`).
- `\u{...}` Unicode escapes in strings/chars; raw strings `r"..."` / `r"""..."""`; triple-quoted `f"""..."""`.
- Nested block comments `/* ... */`.

## Operators & expressions
- `**` / `**=` exponentiation (Int and Float) on all four backends.
- Unary `~` and `+`; compound `&= |= ^= <<= >>=`.
- Conditional expression `a if cond else b`.
- Trailing commas in calls, lists, tuples, parameters, enum payloads, generic and type lists.
- `Char` (and `Str + scalar`) concatenation/interpolation on Cranelift, LLVM, WASM and the MIR interpreter.

## Types
- Function type annotations `fn(A, B) -> R`.
- Generic type aliases (`type Pair[T] = (T, T)`) with arity checking and cycle detection.

## Control flow & patterns
- `range(start, end, negative_step)` counts down.
- Float and raw-string `match` patterns.

## Backend / runtime fixes
- Function values and closures are now distinguished at call sites (non-capturing closures with parameters get a non-NULL env), fixing higher-order calls on Cranelift and LLVM.
- `lpp_file_open` honors flags: `1` sync, `2` exclusive create, `4` truncate, `8` read-only.

## Known remaining
Map/Set literals, slice syntax, named struct literals, expression-form `match`, inline `if cond: stmt`, iterators, operator overloading, a non-blocking I/O reactor, `Send`/`Sync` enforcement, enforced `pub`, and general FFI beyond Cranelift scalars/`Str` remain open (see ROADMAP.md).
