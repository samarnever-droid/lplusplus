# L++ v0.1 release brief

## Identity

- Public release name: **L++ v0.1**

- Cargo package version: **`0.1.0`**
- Campaign line: **Readable. Native. Safety engineered in.**
- Hero proposition: **L++ closes the triangle.**

## Three pillars

### Readable

Python-like significant whitespace, static types with inference, immutable bindings by default, structs, enums, pattern matching, generics, traits, closures, tuples, collections, modules, and `Result` propagation.

### Native

Cranelift-first ahead-of-time compilation with optional LLVM, direct ELF / PE / Mach-O linking paths, native FFI, and direct `wasm32-wasip1` emission without an external WASM linker.

### Safety-first

Validated typed MIR feeds ownership planning, containment and cycle analysis, and static ownership-balance verification. Managed values are planned as `Frame`, `Owned`, or `Shared`; sharing uses ARC where the plan requires it. L++ does not claim that every possible memory, logic, implementation, or unsafe-FFI error is impossible.

## v0.1 technical highlights

- Typed source graph, HIR, inference, MIR, MIR verification, ownership proof, bounded optimization, and target-specific code generation.
- Structs, enums, lists, tuples, slices, maps, closures, function values, tasks, dynamic strings, formatted strings, and the portable builtin surface exercised by the legacy WASM corpus.
- Direct WASM modules are validated with `wasmparser` before leaving the backend.
- Complete positive legacy WASM corpus result: **24/24 compile, 24/24 validate, 24/24 execute, 24/24 exact stdout**.
- Structured rejection of unavailable WASI host capabilities, arbitrary FFI, and SIMD; restricted eager `spawn` is an intentional rewrite-WASM capability.
- Ownership planning and balance remain deterministic across optimization, with executable ARC-oracle coverage.
- Keel/`lpp-pm`: deterministic SemVer backtracking, lockfile v2, validated registries and archives, transitive staging, fingerprints, caching, workspace locking, and offline workflows.

## Claims policy

Approved:

- “Readable. Native. Safety engineered in.”
- “Python-like clarity.”
- “Built for native execution.”
- “Ownership without ceremony.”
- “No VM. No tracing garbage collector.”
- “Common ownership mistakes caught before code generation.”

Do not claim without additional evidence:

- 100% memory safety or that memory leaks are impossible;
- universal backend feature identity;
- benchmark leadership over C, C++, Rust, or Go;
- all-platform support;
- host-only facilities inside the WASI sandbox.
